# Cricket Statistics Dashboard

## About the Project
This project analyzes ODI cricket match data using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- Excel / CSV Dataset

## Dashboard Features
- Total Matches
- Top 10 Teams by Matches
- Match Results Distribution
- Team-wise Match Results
- Matches Won by Each Team
- Matches Played by Year

## Project Objective
To analyze cricket match statistics and present useful insights through interactive visualizations.
